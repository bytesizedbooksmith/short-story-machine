# Short Story Machine

Plan a short story step by step with an AI helper, and get a finished first draft to edit however you like.

> **Beta — testers wanted.** This is a first version and hasn't been run on many stories yet. If something confuses you or the AI goes off track, please [open an issue](https://github.com/bytesizedbooksmith/short-story-machine/issues) and say which AI tool you used.

## Get Started

1. **Download** this folder: green **Code** button → **Download ZIP**, then unzip it.
2. **Open the folder** in your AI tool: Claude Code, Codex, Claude Cowork, ChatGPT Work, Antigravity, VS Code or similar.
3. **Type `start`.**

That's it. The Guide asks a few setup questions the first time, then walks you through your story.

For the full guide, open **START-HERE.html** in your browser (double-click it after unzipping).

## Optional Voice Module

[Stylo Starter](https://github.com/bytesizedbooksmith/stylo-starter) studies your past writing so drafts sound more like you.
