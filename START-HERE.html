Start Here

Plan a short story step by step with an AI helper. It drafts the story for you, checks it, and hands you a finished first draft to edit however you like.

Beta — testers wanted. This is a first version and hasn't been run on many stories yet. If something confuses you or the AI goes off track, please open an issue on GitHub and say which AI tool you used.

  1. Download this folder.
    On the GitHub page, click the green Code button, then Download ZIP. Unzip it somewhere you'll find it again, like Documents.
    Already reading this page on your computer? You've done this step.
  2. Open the folder in your AI tool.
    Pick your tool below to see how.
  3. Type start
    That's it. The Guide takes over from here.

How To Open The Folder

Open the whole folder you unzipped (the one with START-HERE.html in it), not a single file inside it.

Claude Code

In VS Code: choose File → Open Folder, pick this folder, then open the Claude Code panel.

In a terminal: go into this folder and run claude.

Claude Cowork

In the Claude desktop app, start a Cowork task and choose this folder as the folder to work in.

Codex

In the Codex app or VS Code extension: open this folder as your project.

In a terminal: go into this folder and run codex.

ChatGPT Work

Start a new task and choose this folder as the folder to work in.

Antigravity

Choose File → Open Folder, pick this folder, then open the agent panel.

VS Code With Copilot

Choose File → Open Folder, pick this folder, then open Chat and switch it to Agent mode.

Something Else

Any AI tool that can read and write files in a folder will work. Look for an option like Open Folder or choose a working folder.

Menus change often. If yours look different, look for the option to open or choose a folder.
If the AI doesn't seem to know what "start" means, type: Read AGENTS.md, then start

What Happens Next

The first time, the Guide asks a few quick questions about your pen name and what you like to write. That takes about five minutes. Then it walks you through your story:

  • You plan it together: your idea, your people, how the story goes, and the scenes.
  • ✋ You approve the plan. Nothing is written until you do.
  • ✋ You read the opening. The AI drafts Scene 1 first, so you can steer the voice before it writes the rest.
  • The AI writes and checks the rest, with separate reviewers looking for problems.
  • ✋ You get your draft, plus a short note on what was checked. From there, it's yours.

See How It Works for every step.

Three Words To Remember

TypeWhat it does
startBegin, or pick up exactly where you left off.
helpWhere you are and what to do next.
pauseSave everything so you can stop for now.

Otherwise, just talk to it normally.

Good To Know

  • Any genre, any length. Somewhere between 3,000 and 10,000 words is a good place to start.
  • Your work stays in this folder. Your stories go in stories and your style sheet in pen-names.
  • The AI uses your tool's plan or credits. Drafting a whole story takes more than a quick chat does.
  • It gets you started, not finished. You'll still edit the draft, but each story teaches the machine more of what you like.
