Help

The quickest fix for almost anything: type help in your AI tool. It'll tell you where you are and what's next.

I typed "start" and the AI doesn't know what I mean.

Check that you opened the whole folder, not a single file. Then type:

Read AGENTS.md, then start

Some tools read the instructions automatically; others need that nudge once per chat.

I closed the chat. Did I lose everything?

No. Progress is saved in the story's folder after every step. Open the folder again, start a new chat, and type start. The Guide picks up exactly where you left off.

I want to change something I already decided.

Just say so, for example: "Actually, I want the sister to be the villain." The AI updates the plan, saves the old version, tells you which steps it needs to redo, and redoes only those.

The opening sample doesn't sound like me.

That's what step 8 is for. Say what's off in plain words: "too formal," "too much description," "she wouldn't say that." The AI fixes the scene, and voice notes carry into every scene after it. Ask to save a note to your style sheet if it applies to all your stories.

For a bigger boost, try the Voice Module.

My handoff note says "self-review." Is that bad?

It means your AI tool couldn't start a separate reviewer, so the AI checked its own work. It still catches plenty, but it's less independent. The note is honest about it so you know to read a little more closely.

I want to start a second story.

Type start. If you have a story in progress, the Guide will ask whether to continue it or begin a new one.

I write under more than one pen name.

When you start a new story, tell the Guide which pen name it's for. If it's a new one, it runs the quick setup for that pen name first. Each pen name keeps its own style sheet.

I want to skip a step.

You can tell the AI to move on, but the three stops (approving the plan, reading the opening, and handoff) are there to save you heartache. Reading the opening is the most important: catching a problem in Scene 1 is much easier than fixing it in every scene.

It's using a lot of my credits or usage.

Drafting, checking and revising a whole story takes many AI calls. Shorter stories use less. If your tool lets you pick a model, a cheaper one can handle planning; save the best one for drafting.

Where's my finished story?

In stories/your-story-name/FINALS/. See Your Story Folder.
