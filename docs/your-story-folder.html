Your Story Folder

You don't have to manage any files. But here's where things end up, in case you want to look.

The Two Folders That Are Yours

FolderWhat's in it
pen-namesOne folder per pen name, holding its style sheet: your preferences, used for every story.
storiesOne folder per story.

Leave the machine and docs folders alone. They're the machine's instructions and this guide.

Inside A Story

stories/
  the-haunted-bakery/
    FINALS/          ← your finished draft and handoff note
    plan.md          ← your plan: idea, people, shape, scenes
    PROGRESS.md      ← where you are; how the AI picks up next time
    writing/         ← scene drafts and the AI's instructions
    reviews/         ← what each reviewer found
    archive/         ← older versions, never deleted
The one to remember is FINALS. When the machine hands off, your draft is there as Story Title — v1.md.

Opening Your Draft

The draft is a plain text file in Markdown format, which most writing tools can open or paste:

  • Word, Google Docs, Scrivener: open the file in any text editor, copy everything, and paste it in.
  • VS Code or a Markdown editor: open it directly.
  • Or ask the AI to make a Word copy, if your tool can create Word files.

Versions

Nothing is ever overwritten. When something changes, the new version gets the next number (v2, v3) and the old one moves to archive.

Keeping Your Work Private

If you put your copy of the machine on GitHub, your stories and pen-names folders are left out automatically. Back them up some other way, such as a cloud-synced folder or a private repository.
