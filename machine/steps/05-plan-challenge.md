# Step 5 — Plan Challenge

**Goal:** catch problems in the plan before any prose is written. Fixing a plan is cheap; fixing ten drafted scenes isn't.

**Creates:** `reviews/plan-challenge.md`.

## Do This

1. Tell the author in one line: "A challenger is checking the plan for gaps. I'll fix what it finds before you approve."
2. Run the **Challenger** role ([../roles/challenger.md](../roles/challenger.md)) with the **Plan** lens. Give it: the plan, the style sheet. Nothing else.
3. Read its findings. For each one, decide: **fix**, **ask the author**, or **reject** (with a one-line reason in the report).
4. Fix what you can without changing the author's choices (a timing gap, a missing introduction, a vague rule for a magic ability).
5. Anything that would change the author's story (a different ending, cutting a character) becomes a question for Step 6, not a fix.

**Done when:** the fixes are made and the questions are listed. Update `PROGRESS.md`, then go to Step 6.
