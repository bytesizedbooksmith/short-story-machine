# Step 9 — Draft The Rest

**Goal:** a complete first draft, one scene at a time.

**Creates:** `writing/scenes/scene-02.md` onward, and `writing/running-summary.md`.

## Do This

Set the status in `PROGRESS.md` to `drafting`. Then, for each remaining scene, in order:

1. Update that scene's packet from `running-summary.md`: what actually happened in the scenes drafted so far (not what the plan expected), and every **established fact** to the Fixed Facts list. If an earlier scene drifted from the plan, check whether this packet still makes sense.
2. Run the **Drafter** with the brief, this scene's packet, the approved `writing/scenes/scene-01.md` as its **voice example** and `machine/guides/scenes.md`. Nothing else. If it returns a question, follow the Guide's rule for Drafter questions.
3. Read the result. If it breaks the packet (wrong point of view, skips a planned event, reveals something too early, contradicts a fixed fact), redraft once with a note on what to fix.
4. Add this scene to `running-summary.md`, under its scene number:
   - **What happened:** two or three lines, including what changed.
   - **Established facts:** anything a later scene might echo or contradict: what objects and documents are ("the day book," not "a log"), who has what and where it is, ages, numbers, times, promises, injuries. If the scene invented a detail the plan didn't have, it goes here.
   - **Already used:** the scene's standout images, jokes, turns of phrase and repeated gestures. Copy this list into the next packet so later scenes find fresh ones.
5. Update `PROGRESS.md` after each scene, so a `pause` or a closed chat loses nothing.

Don't stop to show the author each scene. Give a short progress line every few scenes if the chat is still open.

**Done when:** every scene on the map has a draft. Then go to Step 10.
